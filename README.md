# 📖 À propos

**Kiassou.dev** est mon portfolio personnel conçu pour présenter mon profil, mes compétences et les différents projets Web et Mobile que j'ai réalisés.

L'objectif est de proposer une interface moderne, fluide et responsive inspirée des sites premium afin d'offrir une excellente expérience utilisateur.

---

# ✨ Fonctionnalités

- 🎨 Interface moderne et élégante
- ⚡ Animations d'apparition au scroll
- 📱 Responsive Design
- 💼 Présentation détaillée des projets
- ❤️ Système de likes
- 💬 Commentaires sur les projets

# 🚀 Installation

### Cloner le projet

```bash
git clone https://github.com/Kiassou/kiassou.dev_web.git
```

### Installer les dépendances

```bash
npm install
```

### Lancer le projet

```bash
ng serve
```

Puis ouvrir :

```
http://localhost:4200
```
